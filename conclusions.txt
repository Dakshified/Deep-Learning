ASSIGNMENT 2: Titanic Survival Classification (Tabular Data / MLP)
--------------------------------------------------------------------------------
- Task: Binary classification to predict survival of passengers on the Titanic.
- Dataset: "titanic (1).csv" (887 records, 6 features used: Pclass, Sex, Age, 
  Siblings/Spouses Aboard, Parents/Children Aboard, Fare).
- Model: PyTorch Multi-Layer Perceptron (MLP)
  - Architecture: Input (6 features) -> Linear(16) -> ReLU -> Dropout(0.2) -> 
    Linear(8) -> ReLU -> Linear(1) -> Sigmoid
  - Training: 100 epochs, Adam optimizer (lr=0.01), Binary Cross-Entropy (BCE) loss.
- Results:
  - Final Test Accuracy: 80.34%
  - Classification Report:
                   precision    recall  f1-score   support
    Not Survived       0.81      0.89      0.85       109
        Survived       0.79      0.67      0.72        69
- What I Understood:
  1. Feature Preprocessing is critical: Numeric features like Age and Fare vary 
     greatly in scale, so standardizing them (StandardScaler) ensures gradients 
     flow stably during backpropagation.
  2. Categorical features like Sex must be mapped to binary numbers (0/1).
  3. Small tabular datasets are highly prone to overfitting. Adding Dropout (0.2) 
     helps prevent the hidden nodes from co-adapting and improves generalization on 
     unseen test data.

ASSIGNMENT 4: Apple (AAPL) Stock Price Prediction (Time-Series / LSTM)
--------------------------------------------------------------------------------
- Task: Regression modeling to forecast closing prices and project next-month trends.
- Dataset: AAPL stock prices (Yahoo Finance yfinance, 5 years historical data).
- Model: PyTorch LSTM Recurrent Neural Network (RNN)
  - Architecture: Input (1 feature) -> LSTM(64 units, return seqs) -> Dropout(0.2) -> 
    LSTM(32 units, final state) -> Dropout(0.2) -> Linear(16) -> ReLU -> Linear(1)
  - Training: 50 epochs, Adam optimizer (lr=0.001), MSE Loss, Early Stopping (patience=10).
- Results:
  - Test RMSE: 8.92 USD
  - Test MAE: 6.82 USD
  - Test MAPE: 2.37%
  - Next Day Prediction: $300.89 (Last Actual: $311.30)
  - 1-Month (21 trading days) forecast predicts a downward change of -15.68% ($262.47).
- What I Understood:
  1. Time-series sequence processing: Recurrent architectures (LSTMs) are ideal 
     for sequence data because they maintain a cell state (memory) to capture temporal 
     dependencies over a sliding lookback window (60 days).
  2. The limitations of recursive forecasting: Predicting further into the future 
     (e.g., 21 days) by feeding predictions back into the model as new inputs tends 
     to accumulate errors, causing the predictions to smooth out or regress to 
     the historical mean.

ASSIGNMENT 5: IMDb Movie Review Sentiment Classification (NLP / Logistic Regression)
--------------------------------------------------------------------------------
- Task: Binary classification of movie reviews into positive or negative sentiments.
- Dataset: IMDb Movie Reviews dataset (50,000 reviews).
- Model: TF-IDF Vectorizer + Scikit-Learn Logistic Regression
  - Vectorizer: TF-IDF (unigrams + bigrams, max features 25,000, English stop words).
  - Training: Logistic Regression, trained on 40,000 samples, tested on 10,000.
- Results:
  - Final Test Accuracy: 90.18%
  - Classification Report:
                   precision    recall  f1-score   support
        negative       0.91      0.89      0.90      5000
        positive       0.89      0.91      0.90      5000
- What I Understood:
  1. Text Preprocessing: Cleaning HTML tags, punctuation, and lowercasing 
     standardizes textual input and reduces vocabulary noise.
  2. TF-IDF vectorization: Scoring terms based on frequency (TF) and document 
     rarity (IDF) represents documents as high-dimensional sparse vectors, 
     capturing lexical meaning effectively.
  3. Simple models are powerful: Logistic Regression trains in under 5 seconds and 
     exceeds 90% accuracy on high-dimensional text data, proving that deep neural 
     networks are not always necessary for standard text classification.

ASSIGNMENT 6: Tomato Leaf Disease Classification (Computer Vision / CNN)
--------------------------------------------------------------------------------
- Task: Image classification of tomato leaves into 4 categories of health/disease.
- Dataset: 3,966 tomato leaf images split 80% train / 20% validation.
- Model: Comparative PyTorch CNNs
  - Model 1 (1-Layer Conv): Conv2d(16) -> ReLU -> Flatten -> Linear(4)
  - Model 2 (Conv + Pool): Conv2d(16) -> ReLU -> MaxPool2d(2,2) -> Flatten -> Linear(4)
  - Model 3 (Conv + Pool + Dense): Conv2d(16) -> ReLU -> MaxPool2d(2,2) -> Flatten -> 
    Linear(128) -> ReLU -> Linear(4)
- Results:
  - Model 1 Val Accuracy: 87.91%
  - Model 2 Val Accuracy: 87.15%
  - Model 3 Val Accuracy: 89.55%
- What I Understood:
  1. Convolutional layers act as local feature extractors (edges, shapes, textures) 
     using shared kernels.
  2. Max Pooling layers achieve spatial downsampling, reducing computing costs, and 
     providing translation invariance by retaining maximum activation features.
  3. Fully connected (Dense) hidden layers combined with pooling enable the network 
     to capture global spatial feature interactions, boosting validation accuracy 
     from 87.15% to 89.55%.
